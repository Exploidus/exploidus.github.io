Linux Kernel: Task Field Reset on Exit of an SCX_TASK_READY Task

Linux Kernel · sched_ext

Tasks in the SCX_TASK_READY state remain attached to a scheduler but outside the ext scheduling class (such as RT/DL tasks, or non-SCHED_EXT tasks under a partial switch). BPF schedulers update their dsq_vtime and slice during operations like cgroup movements. Previously, __scx_disable_and_exit_task() broke out of the state switch without invoking scx_reset_task_fields(), leaving stale timing fields uncleared across migrations between sub-schedulers. The patch adds scx_reset_task_fields() to the SCX_TASK_READY exit path to ensure managed scheduling fields are properly cleared.

Target Tree
sched_ext/for-7.4-fixes (Linux 7.4 release tree)

NASA F Prime: FileHandling Subtopology Framework Dependency Resolution

NASA JPL · F Prime

In NASA Jet Propulsion Laboratory F Prime flight software, subtopology configurations define core infrastructure constants for mission flight deployments. Following architectural refactoring to compile string constants in FppConstantsAc.cpp, FileHandlingConfig lacked an explicit dependency on the Fw_Types target. NASA F Prime: CCSDS CFDP Metadata PDU Closure Flag Specification Fix

NASA JPL · F Prime

F Prime is NASA Jet Propulsion Laboratory open-source flight software framework used across CubeSats, planetary landers, and robotic exploration missions. In the CCSDS File Delivery Protocol (CFDP) manager component, the closure requested flag in Metadata PDUs was incorrectly mapped against bitmask 0x04 instead of bit 0x40 as mandated by the CCSDS 727.0-B-4 blue book specification. This mismatch caused flight file uplink sessions requesting explicit transaction closure to mishandle final acknowledgement state machines. The fix corrected the bitmask constant and resolved transaction stalls across deep-space telemetry pipelines.

Microsoft VS Code: Portable Environment Isolation and Case-Insensitive CLI Quality Parsing

Microsoft · VS Code

Visual Studio Code is the industry-standard developer environment deployed across millions of workstations. The patch enforced strict environment hierarchy validation and normalized release quality tokens across all supported operating systems.

Linux Kernel Sched-ext: scx_intent 5-Tier Intent-Driven CPU Scheduling

Linux · sched-ext

Standard desktop and server Linux workloads frequently encounter micro-stuttering and latency spikes when background compute processes compete for execution slots with interactive window compositors and real-time audio threads. Exploidus authored scx_intent as a native in-kernel eBPF scheduler and contributed it upstream to the Linux sched-ext framework to deliver deterministic priority isolation without complex cgroup management overhead.
