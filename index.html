Aegis-Filter Core

4.07 ns #![no_std] Zero-Allocation State Estimation & FDIR for Edge AI

High-integrity state estimation engine implementing Unscented Kalman Filtering (UKF), continuous-discrete extended filters, and Joseph-form covariance stabilization. Engineered specifically for Edge AI robotics, supersonic UAV guidance, LEO satellite attitude control, 8KHz ultra-high-frequency sensor smoothing, and low-latency algorithmic systems.

  • Zero-Heap Allocation: Guarantees zero runtime memory allocations and zero page faults in critical flight loops.
  • Joseph Covariance Stabilization: Mathematically guarantees positive semi-definiteness even with round-off errors.
  • Multi-Sensor FDIR: Real-time Fault Detection, Isolation, and Recovery with consecutive anomaly thresholding.

scx_intent BPF

Intent-Driven 5-Tier Preemptive Kernel Scheduler

Pure in-kernel eBPF CPU scheduler designed for sched-ext (Linux 6.12+ and 7.4+). Dynamically categorizes tasks into 5 dedicated Dispatch Queues: Audit, Interactive, IO, Network, and Compute—eliminating priority inversion and micro-stuttering under saturated multi-core workloads.

  • Dedicated BPF DSQs with multi-tier starvation relief.
  • Sub-microsecond task dispatch with zero user-space latency.
  • CachyOS and high-performance gaming/simulation tuned.
scx_intent --interactive-boost --anti-starve

XDP-Guard Ingress

100 Gbps Line-Rate Driver-Hook eBPF DDoS Shield

High-performance eBPF/XDP network defense engine operating directly at the NIC driver DMA layer. Drops multi-gigabit SYN floods, UDP reflection amplification, and malicious malformed payloads before socket memory allocation occurs.

  • Line-rate XDP_DROP at hardware wire-speed (<100 ns).
  • Native Prometheus metrics exporter & Grafana dashboard.
  • Kubernetes DaemonSet with automated Helm deployment.

SPECIFICATION // TIER 01: XDP-GUARD DRIVER HOOK
• Hook location: XDP_DRV (Direct Network Interface Card DMA buffer)
• Action: Evaluates SYN cookies, ACK flood patterns, and reflection signatures via eBPF BPF_MAP_TYPE_LRU_HASH.
• Return: Emits XDP_DROP instantly, preventing Linux sk_buff memory allocations under volumetric attack.
